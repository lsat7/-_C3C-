# -_C3C- — 双人协作与技能迁移（Peer Collaboration & Skill Transfer）

本仓库是挑战 **C3C** 的双人联合交付物。组合为「计算机 + 金融」跨专业二人组：搭档 lsa（CS 方向）负责工程实现，搭档 lsa（金融方向）负责领域口径与验收。核心不是分工，而是互教——双方各自教会对方一项原本不会的技能，并共同产出一个任一方单独无法完成的项目。

## 项目简介

联合产出是一个**个人收支与投资组合健康度分析工具**：把金融搭档定义的指标口径固化为可复用的 Python 模块，由 CS 搭档实现数据读取、指标计算与零依赖 HTML 报告渲染。项目同时是知识迁移的载体——工具代码、单元测试、教学记录与前后对比共同构成「1+1>2」的证据链。

项目目标：

1. 让非 CS 搭档把手工财务口径变成可重复运行的工具；
2. 让 CS 搭档能独立使用领域方法论完成专业预算判读；
3. 产出可运行、可测试、可离线展示的 HTML 分析报告。

## 快速开始

工具位于 `lsa-lsa_C3C_联合产出/`，只依赖 Python 标准库，无需安装第三方包。

环境要求：Python 3.8 及以上（实测 3.13.14）。

```bash
cd lsa-lsa_C3C_联合产出
python analyze.py --transactions data/transactions.csv --nav data/nav.csv --budget 8000 --out report.html
```

运行后用浏览器打开生成的 `report.html` 即可查看报告。完整参数、数据格式与测试方式见 [`lsa-lsa_C3C_联合产出/README.md`](lsa-lsa_C3C_联合产出/README.md)。

## 主要功能

- 按收入、支出汇总逐月结余与结余率；
- 统计支出科目占比，输出全期与最新月份视图；
- 计算累计收益、年化收益、年化波动、夏普比率与最大回撤；
- 按「预算控制 60% + 结余率 40%」给出预算健康度评分与建议；
- 生成内联 SVG 图表、可离线打开的 HTML 报告。

## 测试

```bash
cd lsa-lsa_C3C_联合产出
python -m unittest discover -s tests -v
```

6 条用例覆盖数据加载、按月汇总、科目占比、组合指标、预算评分与异常输入，实测全部通过。

## 配置说明

工具无独立配置文件，配置通过命令行参数与 CSV 完成：

| 配置项 | 位置 | 默认值 | 说明 |
|--------|------|--------|------|
| 收支流水 | `--transactions` | `data/transactions.csv` | 列：`date,category,amount,type,note`；`type` 仅允许 `income`/`expense` |
| 净值序列 | `--nav` | `data/nav.csv` | 列：`date,nav`；净值须为正数，按日期升序处理 |
| 月度预算 | `--budget` | `8000` | 用于预算健康度评分，单位元 |
| 报告输出 | `--out` | `report.html` | 输出路径，父目录不存在时自动创建 |
| 年化交易日 | `finance_metrics.py` 常量 `TRADING_DAYS` | `252` | 修改需同步复核测试期望值 |
| 无风险利率 | `finance_metrics.py` 常量 `RISK_FREE_RATE` | `0.02` | 用于夏普比率计算 |

## 已知限制

- 净值样本仅 15 个观测点，年化收益 387.54% 为短样本外推值，报告与文档均已标注警示，不构成投资判断；
- 预算健康度为教学用简化模型，未纳入收入波动、负债与通胀因素；
- 教学记录为聊天记录与终端输出形式，仓库内不含截图或录屏文件。
